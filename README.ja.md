# GitHub初心者向け 見学用Repository

このRepositoryは、書籍の画面見学用教材です。

- ファイルや履歴を自由に見てください。
- 教材目的以外のIssueやPull Requestは作成しないでください。
- 質問は本書・公式サイトで案内する質問窓口をご利用ください。

## 見学する場所

まずは Code / Commits / Branch / Pull requests / Actions を見ます。

現在のGitHubでは、Repositoryによって **Security and quality** が表示されます。
また、Copilot coding agentなどの対応機能が有効な場合は **Agents** タブが表示されることがあります。
タブは権限・契約・機能設定・画面幅によって同じように見えない場合があります。
